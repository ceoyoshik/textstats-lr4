Найдено и исправлено в ходе ревью:

1. В тесте токенизации в набор входило слово «знаки», хотя ожидался пустой
   результат — ожидание исправлено.
2. Тесты `parse_response` собирали сообщение через `build_response` с
   заведомо неверным типом, из-за чего падал сам конструктор; сообщение
   теперь собирается корректно, проверяется именно разбор.
3. Ошибки стиля: пустая строка между импортами и функцией (E302),
   выравнивание продолжения строки (E128), длина строки (E501) — исправлено.
