# План и результаты тестирования (ЛР №4, вариант 11)

Объект тестирования — консольная программа **«ТекстСтат-11»** (система
обработки текста): статистика символов, слов, предложений, уникальных слов,
средней длины слова, самого длинного и самых частых слов.

## 1. Соответствие варианту 11

| Требование варианта | Значение по заданию | Фактически |
| --- | --- | --- |
| Предметная область | система обработки текста | «ТекстСтат-11» |
| Метод тестирования | покрытие решений | все ветки `if/else` пройдены в обе стороны |
| Инструмент | pytest (Python) | pytest 9.2, pytest-cov |
| Целевое покрытие | не менее 75 % | 100 % операторов, решений и условий |

Дополнительно (уровень 3): покрытие условий, комбинаторное покрытие,
граничные значения, интеграционные и регрессионные тесты, CI/CD.

## 9. Выводы

1. Все требования варианта 11 выполнены: pytest, покрытие решений,
   покрытие 100 % при требуемых 75 %.

   исправлены и закрыты тестами.

   тайм-аут и CLI, а не только заглушки.
4. Регрессионный набор автоматически защищает эталонные результаты.
